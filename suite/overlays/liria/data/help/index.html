The window

The header row holds Back, Forward and Parent Folder, the path of the current folder, the view switcher (icons, list, compact), Search and the main menu. Click a part of the path to go there; click the pencil button, or press Ctrl+L, to type a location instead.

The sidebar lists Favorites (your home and personal folders), Devices (the file system and drives), Bookmarks and Network. Press F9 to show or hide it. Above your home folder, the Home overview shows Quick access, drives with their free space and your recent files.

Quick access holds what you pin: folders, documents, pictures, archives, server locations or folders on a USB drive. Pin an item with Pin to Quick Access in its right-click menu (in the file view or the sidebar), by dropping it on the Quick access cards or with the + card. A folder opens in the window; a file opens in its usual application. Right-click a card (or press Shift+F10) to rename it, move it left or right, unpin it or reset Quick access to the default folders. Drag a card to move it, Delete unpins the focused card, F2 renames it and Ctrl+Shift+Left/Right moves it. Items that were moved, deleted or are on a drive that is not connected are dimmed and marked Not available. The list is kept in ~/.config/sde/liria-quick-access, one location per line, and every open window follows changes to it.

Menus

The main menu (F10) opens new windows and tabs, a terminal in the current folder, connections to servers, hidden files, sorting, view options, bookmarks, preferences, keyboard shortcuts and this help. Right-click a file for Open, Open With, Cut, Copy, Rename, Copy To, Move To, Send To a removable drive, Compress or Extract, Move to Trash and Properties. Right-click the background of a folder to create folders and documents or to paste.

Selecting files by name

Press Ctrl+S and type a pattern: * matches any text and ? one character, for example *.jpg or report-??.pdf.

Opening a location

Type a folder path such as /media, a network address such as sftp://server/home, or ~ for your home folder.

Bookmarks

Press Ctrl+D to bookmark the current folder; it appears in the sidebar and under Main Menu › Bookmarks. Ctrl+B edits, renames or removes bookmarks.

Removable drives

Copies to USB sticks and memory cards are written through to the drive, so the progress shows what really reached the device, and the operation ends with Finishing while the last data is written. Names that FAT, exFAT or NTFS cannot store are adjusted, and files of 4 GB or more are refused on FAT32 with a clear message. Use Send To in a file's menu to copy it to a drive. Always use Eject or Safely Remove in the sidebar before unplugging: Liria first writes all cached data to the drive.

Connecting to a server

Main Menu › Connect to Server opens SFTP, FTP, Windows shares (SMB) and WebDAV locations. Saved connections appear in the sidebar under Network.

File properties

Press Alt+Return to see a file's size, type, location, dates, permissions and the application that opens it.

Backgrounds and emblems

Emblems mark files and folders with small symbols. The desktop wallpaper is set in SDE Settings, or with Set as Wallpaper in a picture's menu.

Preferences

Main Menu › Preferences sets the default view and icon size, whether one or two clicks open items, what happens with executable text files and the trash, and whether the Delete command bypasses the trash.

Display: the information shown under icon names and the date format.

List Columns: the columns of the list view and their order.

Preview: thumbnails, item counts and previews for local and remote files.

Media: what happens when a disc, camera or drive is inserted.

Keyboard shortcuts

Press Ctrl+? in Liria for the complete list. The most used: Ctrl+T new tab, Ctrl+F search, Ctrl+H hidden files, Ctrl+1/2/3 icons/list/compact view, F2 rename, Delete move to trash, F3 extra pane.
