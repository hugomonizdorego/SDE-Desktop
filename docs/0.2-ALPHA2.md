# SDE 0.2 Alpha 2 — Merkadu, tile groups, user accounts and Liquid Glass

Development patch of the **Selviana Desktop Environment** (`0.2.0~alpha2`),
amd64, built and tested on Debian testing. It follows
[0.2 Alpha 1](0.2-ALPHA1.md); the way to 1.0 is in [ROADMAP.md](ROADMAP.md).
Still alpha: test it in a virtual machine or a spare installation first.

![The Start Menu of SDE 0.2 Alpha 2 with tile groups by category](screenshots/0.2-alpha2/01-start-menu.jpg)

## Merkadu, the new software center

**Merkadu** ("market") finds, installs, updates and removes software from
three sources in one window:

- **Debian** packages through PackageKit, described by the archive's
  AppStream catalog (names, icons, screenshots, categories).
- **Flatpak** apps from Flathub (system installation; Merkadu offers to add
  Flathub when it is missing).
- **Snap** apps through snapd.

An app that exists in several sources appears once, with a badge for each
source and a choice on its page. Explore (featured, new and top apps — the
lists are set by the distribution in `/etc/merkadu/merkadu.conf`), departments with
subcategories, Installed grouped by department, Updates, History (APT,
Flatpak and Snap) and In Progress are carried over from **Ubuntu Software
Center** (Canonical, GPL-3.0), credited in About and in the legal data;
nothing depends on its retired online services. While software is
installed or removed, the SDE logo animates its three color stripes.

Merkadu is its own package, `merkadu` (`sde-desktop` recommends it). The
Welcome tile **Software** and Control Center → **Applications** open it.
Details: [MERKADU.md](MERKADU.md).

### Snap and the home folder

snapd keeps each user's snap data in `~/snap`. That folder cannot be moved
to `/usr/share/SDE/SNAPD` or any other shared folder: the data belongs to
each user and must stay writable by them, and the AppArmor confinement of
every snap only allows `@{HOME}/snap` or `@{HOME}/.snap/data`. Moving it
elsewhere would break every confined snap. What snapd supports is to hide
it: before the first snap is installed, Merkadu asks (with your password)
to turn on `experimental.hidden-snap-folder`, and snap data then lives in
the hidden `~/.snap/data` instead of a visible `~/snap`. The reasons, with
references to snapd's sources, are in [MERKADU.md](MERKADU.md#the-snap-folder).

## Start Menu

- **Typing always searches.** Pressing a letter while the category filter
  ("All apps") or a context menu was open jumped to a category or did
  nothing, and closing such a popup gave up the keyboard. Every letter now
  goes to the panel search, from wherever it is typed; the A–Z grid still
  opens from a letter heading.
- **Tile groups by category.** For everyone who has not arranged tiles
  yet, the tiles are grouped by category: Internet (browsers, mail, chat),
  Office, Multimedia, Graphics, Development, Games, Education & Science,
  System & Settings and Accessories, only those with apps. The groups of
  0.2 Alpha 1 (Productivity, Explore) are turned into category groups;
  tiles of your own stay.
- **Drag and drop:** drag tiles between groups, or apps from the list or
  the search results into a group; drop on "New group" to make one; click a
  group name to rename it; drag a name to move the group; empty groups can
  be removed. An insertion bar, a highlighted group and a ghost tile show
  where the tile lands, and the tiles scroll near the edges.
- **Uninstall…** in the right-click menu of an app (list, tiles, search)
  asks Merkadu to remove it, with a confirmation that names the package and
  what else is removed; SDE's own applications cannot be removed alone.
- **Icons for every app.** Apps whose icon is missing from the icon theme
  get the closest match (the desktop id, the program, the window class,
  names without `-symbolic`), Papirus or Adwaita, or an icon for their
  category instead of a grey square. "Advanced Network Configuration" has a
  new SDE icon.
- It stays fast (320 apps, median): Super opens it in 3.6 ms (was 4.7 ms),
  a keystroke shows results in 2.6 ms, scrolling glides at 62 fps.

## Control Center

- **Maximized windows.** The Control Center window never followed its own
  size: maximized, the page kept its first size, which left a grey band
  under it, and the sidebar scrolled its header away. Sidebar and page now
  fill the window at any size; the content stays at a readable width,
  centered; the sidebar header and footer stay in view. Display Settings
  can be resized and maximized too.
- **User accounts** on Users & Avatar, with AccountsService and polkit as
  on other Linux desktops:
  - add a user: full name, a user name made from it (Debian's rules),
    Standard or Administrator (the sudo group), a password with a strength
    meter and confirmation, or "ask at first login";
  - change the type, set a password (stored only as a yescrypt or SHA-512
    hash), lock or unlock, automatic login, name and picture;
  - remove a user and keep or delete the files;
  - change your own password (passwd, without a shell).
  You cannot remove, lock or demote yourself or the last administrator.
- **75 % and 175 %** interface sizes in Appearance, Displays and Display
  Settings; text never gets smaller than 9 px, GTK applications follow
  (Xft.dpi).
- **About** shows the build number and the commit in the packages too
  ("Build: Unknown" in 0.2 Alpha 1).
- **Applications** opens Merkadu.

## Panel: battery and clock

- **Battery:** it fills while charging, turns amber and pulses gently when
  low, red when critical, and shows a plug when full. Animations repaint
  only the icon and stop with reduced motion.
- **What the panel shows** after the icon: nothing, the percentage, a label
  ("Charging", "On battery"…), or label and percentage, and optionally the
  time — from the icon's right-click menu or Control Center → Power →
  Battery.
- **Time estimates:** "1 h 10 min to full" while charging, "3 h 57 min
  left" on battery, from UPower or computed from the charge rate with
  smoothing, and "Calculating…" while not known yet.
- **Clock:** the styles are Digital, LED and Analog. **Show seconds** and
  **Blink the colon** are now two independent switches (Control Center →
  Clock & Weather, and the right-click menus of the panel clock and the
  Action Center clock); "Blink" settings of earlier versions are kept.

## Liria

- **Icon:** the folder stays, the lily is gone.
- **Ribbon in color:** the commands use the icons of the chosen icon
  theme, in color where the theme has them, and follow icon theme and
  scale changes at once.
- **Faster with big folders** (10 000 files, median):

  | | Before | After |
  | --- | --- | --- |
  | Open the folder | 1.41 s | 1.01 s |
  | Switch to the compact view | 7.94 s | 1.16 s |
  | Switch to the icon view | 6.38 s | 1.33 s |
  | Switch to the list view | 7.86 s | 3.04 s |
  | Select all | 1.00 s | 0.49 s |

- **Copy and move progress like Windows 10:** a speed graph, the current
  file, time and items remaining, pause, queue and cancel, and the
  animated SDE logo. Large files now report progress (and pause) while they
  are copied. The SDE desktop uses the same dialog for drag and drop and
  paste.

## Themes and SDE Liquid Glass

- **Every theme redesigned** (SDE Graphite, SDE Fluent, SDE Liquid Glass;
  light and dark): calmer palettes with checked contrast, consistent
  corners, light rims on popups and menus, new switches and sliders, one
  clear focus ring, and sharp window buttons at 125–200 %.
- **SDE Liquid Glass** (formerly SDE Glass) now looks like the
  [liquid-glass](https://github.com/ryohsuke1231/liquid-glass) design: the
  panel, menus, popups, notifications and tooltips are clear glass that
  blurs and slightly bends what is behind it, with a light rim — a
  compositor shader (SDE Compositor patch) does it. Text stays readable on
  any background. It needs OpenGL (in VirtualBox, turn on 3D acceleration);
  without it SDE draws a frosted glass instead.

## Niny, Welcome and windows

- **Niny's Settings page scrolls and works.** Its scroll bar was only a
  picture; now it can be dragged and clicked, the wheel and Page keys
  glide, and Tab or the arrow keys reach every setting.
- **Title bars stay on the screen.** At 1920×1080 with 150 % the title bar
  of Niny, Gallery, Photo, Xanara, Taca, System Monitor, Calculator, the
  Control Center and Welcome was placed above the top of the screen.
- **SDE Welcome for distributions:** its texts, icons and commands are
  files in `/usr/share/SDE-Welcome` (`welcome.conf` and one
  `steps/*.desktop` file per tile), which a distribution changes in
  `/etc/SDE-Welcome`. New tiles: Software (Merkadu) and Control Center.
  See [WELCOME.md](WELCOME.md).

## Tests

All automated tests pass: the unit tests, the panel and UI smoke tests at
1366×768 and at 1024×600 with 150 %, and the About windows of the
installed programs. New tests cover Merkadu (model, window, uninstall),
user accounts, the battery estimates, the clock options, tile groups and
icon fallbacks, the copy progress, Liria's ribbon and progress, Welcome's
files and the build number of packages.

What could not be tested here: real installs and removals through
PackageKit, Flatpak and snapd, and real account changes through
AccountsService (the build machines have no system services; fake
services were used). Please try them on a real installation.

## For the project owner

1. **Snap data stays in the home folder** (hidden as `~/.snap/data`), see
   above; `/usr/share/SDE/SNAPD` is not possible with snapd.
2. **Merkadu's Explore lists** (featured apps) are a distribution choice:
   `/etc/merkadu/merkadu.conf`.
3. **SDE Welcome** can now be tailored for DebION in `/etc/SDE-Welcome`
   (for example the Donate and Help tiles).
4. **User names cannot be renamed** after an account is created
   (AccountsService does not offer it).
5. **Translations:** many texts are new; Indonesian first.

## Install for review

```sh
sha256sum -c SHA256SUMS
sudo apt install ./sde_0.2.0~alpha2_amd64.deb ./sde-desktop_0.2.0~alpha2_all.deb \
                 ./merkadu_0.2.0~alpha2_amd64.deb
# DebION GNU/Linux integration (optional, recommended on DebION):
sudo apt install ./debion-desktop-base_0.2.0~alpha2_all.deb
```

Log out and choose **SDE-Desktop** at the login screen. If something
crashes, send `~/.local/state/sde/session.log` (or use System Reports).
