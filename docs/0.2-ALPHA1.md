# SDE 0.2 Alpha 1 — identity, Control Center and a faster Start Menu

Development patch of the **Selviana Desktop Environment** (`0.2.0~alpha1`),
amd64, built and tested on Debian testing. It is the first release of the
0.2 series and follows 0.1 Alpha 52; the way to 1.0 is in
[ROADMAP.md](ROADMAP.md). Still alpha: test it in a virtual machine or a
spare installation first.

![The Start Menu of SDE 0.2 Alpha 1](screenshots/0.2-alpha1/03-start-menu.jpg)

SDE is a desktop environment. **DebION GNU/Linux** is a separate project, a
Debian-based distribution (Linux kernel) that ships SDE. This release keeps
the two apart: see [SDE and DebION](#sde-and-debion) below.

## The official SDE logo

- The logo (retro screen, portrait line art, RGB stripes, "SELVIANA DESKTOP
  ENVIRONMENT") is installed in `/usr/share/sde/branding` in light and dark
  versions, as PNG and SVG, plus a square mark and the `sde-logo` icon with
  hand-drawn 16–32 px sizes.
- It is used **only in important places**: the About windows, Control
  Center → About, Welcome, the SDE entry of the login screen and the README.
  Panels, menus and launchers use the application icons.
- Clear space, minimum sizes, light/dark use and what is not allowed are in
  [BRANDING.md](BRANDING.md).

## Icons for every SDE application

One family, drawn for SDE (SVG masters and hand-tuned 16, 24 and 32 px
sizes): Liria, Niny, Xanara, Taca, Photo, Gallery, System Monitor,
Calculator, Control Center, Software Updater, Welcome, Driver Manager, System
Reports, Run, Display Settings, Screen Lock, Power and Log Out. Each one shows
what the program does: a folder with a lily for Liria ("lírio" is a lily), a
notepad and pencil for Niny, a document with a bookmark ribbon and a pen nib
for Xanara, a box closed with a zipper for Taca, and so on. The sheet is
[docs/branding/icon-sheet.png](branding/icon-sheet.png). Every application
now also shows its icon in its title bar and on its taskbar button.

## About windows: copyright, licenses and trademarks

Every SDE application has the same About window with four sections:

- **About** — name, version, what it does, website.
- **Credits** — authors and the upstream projects it uses.
- **License** — the license with a **View License** button for the full
  text, and **Open-source licenses** for every bundled component.
- **Legal** — the official copyright line and only the trademark notices
  that apply:
  - "Selviana Desktop Environment, SDE and the SDE logo are trademarks of the
    Selviana DE Project."
  - Linux®, Debian and PayPal notices only where those names appear.

The data comes from one file, `/usr/share/sde/legal/components.json`, which
a test checks against the SPDX header of every source file, the AppStream
files and `debian/copyright`. Programs also answer `--version` with the
copyright and license. Details: [LEGAL.md](LEGAL.md).

## Control Center (was SDE Settings)

- **SDE Settings is now the Control Center**, one central place for every
  setting. It opens on an overview with search and tiles by category:
  Personalization, System, Network & Internet, Devices, Administration,
  Applications and About.
- **New pages:** Users & Avatar, Start Menu, Date & Time.
- The `sde-settings` and new `sde-control-center` commands open the same
  window; old page names and settings keep working.

## User pictures (avatars)

- Change your picture in **Control Center → Users & Avatar** or from the
  **account button of the Start Menu**. Pick one of the samples, any PNG,
  JPEG or SVG of your own, or remove it (initials are shown instead).
- Two sample pictures are installed in **`/usr/share/Avatar`**:
  `sde-retro.png` and `sunrise.png`.
- The picture is cropped to a square, saved as `~/.face`, and handed to
  AccountsService for the login screen. The Start Menu, the lock screen and
  the Control Center update at once. The real name can be changed too (with
  AccountsService).

## Start Menu: faster and reliable

Measured on 347 applications, median before → after:

| | Before | After |
| --- | --- | --- |
| Open with Super | 18 ms | 4 ms |
| First open after the panel starts | 32 ms | 8 ms |
| First open after a reboot (cold disk cache) | 1393 ms | 62 ms |
| Keystroke → search results | 17 ms | 2 ms |
| Wheel scrolling | 72 px jumps, 33 fps | smooth glide, 60 fps |

- **Super always opens the menu.** 1 to 10 of 100 presses were lost under
  load; now none. Super also closes the menu and the search.
- Applications are read once and watched for changes, so an installed or
  removed app appears at once. Icons load in the background.
- Keyboard: Tab order, Home/End, Shift+F10; Super+Space no longer launches
  the selected app.
- Search understands accents ("ecrire" finds "Écrire"), letters in order
  ("blf" finds Bluefish), keywords and "control center", "control panel" or
  "settings".
- New **App info** and **Open file location** in the right-click menus; one
  Power off confirmation only; menu and search follow theme changes while
  open.

## Liria

- **The rubber-band selection is visible again.** Dragging with the mouse
  to select files showed an opaque white sheet that hid the files; it is now
  a light, translucent accent band with a thin border, in every SDE theme
  (light and dark) and in Liria's own style sheet.
- Selected icons are no longer darkened; the sidebar headings have the same
  height; the location entry is as wide as the breadcrumbs; the ribbon
  scrolls with the wheel; About names the Caja/MATE authors and the SDE
  copyright.

## Security and quality

A release audit reviewed the builds, the privileged parts and the new code:
47 findings, every High and Medium one fixed. The report is
[AUDIT-0.2.0-alpha1.md](AUDIT-0.2.0-alpha1.md), the policy
[SECURITY.md](SECURITY.md).

- **High (fixed):** `debion-network-check --apt-proxy` accepted a value with
  a line break, which let a local user write any APT option as root through
  pkexec. Only single-line proxy URLs are accepted now, and pkexec allows
  only the desktop's own actions.
- **Medium (fixed):** a bad tray icon name could crash the panel; read
  overruns in notification images, Gallery photo metadata and Xanara stamp
  images; Xanara opened `file:` links in PDFs without asking; the runtime
  directory fallback could follow another user's links; crash fixes in SDE
  WM.
- **Also fixed:** lock screen and polkit agent wipe password copies;
  HTTPS fetches stay HTTPS; logind signals are accepted only from logind;
  SDE WM is a release build again.
- **Desktop and panel at login:** when the window manager started at the
  same moment, the desktop or the panel could stay invisible. They now set
  their window type before they are first shown (SDE-FLTK 1.3.11-sde3).
- No compiler warnings with GCC 13 or Clang 18. All automated tests pass
  (the unit tests also under AddressSanitizer and UBSan; the UI tests at
  1366×768 and at 1024×600 with 150 % scale).

## SDE and DebION

- Developer everywhere: **Selviana DE Project**. Copyright: "Copyright ©
  2026 Selviana DE Project and contributors".
- `sde-desktop` no longer requires `debion-desktop-base` (only recommends
  it); the login greeter uses the active desktop-base background, not a
  DebION file.
- Welcome says "Welcome to" the name of the installed system (from
  `/etc/os-release`), not a fixed distribution name.
- Technical ids such as `org.debion.*` stay unchanged so that settings and
  file associations keep working ([LEGAL.md](LEGAL.md#historical-identifiers)).

## Decisions for the project owner

These need the owner, not a code change:

1. **Text under the logo.** The footer of the original logo image says "GNU
   General Public License v2.0", "Forked from edeproject.org", "®" and "All
   rights reserved". SDE is GPL-3.0-or-later, contains no EDE code (inspired
   by EDE), its name is not a registered trademark, and "All rights reserved"
   contradicts a free license. The installed logo files therefore leave the
   footer out. Suggested footer: "© 2026 Selviana DE Project · GPL-3.0-or-later
   · inspired by EDE".
2. **Copyright holder.** "Selviana DE Project" is not a legal entity; the
   contributors keep their copyright. If a person or an organisation should
   be named, change `data/legal/components.json` (one place).
3. **Trademark.** Use "®" only after the name or logo is registered.
4. **Themes** derived from Graphite and Flat Remix are GPL-3.0-only, as their
   upstream license files have no "or later".
5. **Donations:** the PayPal button goes to a personal account; say so on the
   website if that stays.

## Install for review

```sh
sha256sum -c SHA256SUMS
sudo apt install ./sde_0.2.0~alpha1_amd64.deb ./sde-desktop_0.2.0~alpha1_all.deb
# DebION GNU/Linux integration (optional, recommended on DebION):
sudo apt install ./debion-desktop-base_0.2.0~alpha1_all.deb
```

Log out and choose **SDE-Desktop** at the login screen. If something
crashes, send `~/.local/state/sde/session.log` (or use System Reports).
